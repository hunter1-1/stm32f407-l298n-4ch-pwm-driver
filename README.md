# STM32F407 PWM 调速与四路有刷直流电机驱动板设计

设计双 L298N 四路有刷直流电机驱动板，集成 LM2596S-5.0 降压电路，并配合 STM32F407 完成 PWM 调速与电机正反转联调。

![L298N 四路驱动板 3D 渲染](./L298N四路驱动%2B5V降压模块_图片展示.png)

## 固件功能

- 基于野火 STM32F407 定时器例程，使用 TIM2 输出 PWM，通过按键调节占空比，并用 GPIO 控制电机正反转。
- 使用 TIM8 捕获 PWM 信号，通过 USART1 输出测得的频率和占空比。
